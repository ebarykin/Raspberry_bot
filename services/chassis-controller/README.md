# chassis-controller

Узел ROS 2 Jazzy. Единственное место, где команды движения доходят до железа.

Тяга: плата IBT-2 (BTS7960), ШИМ с PCA9685 по I2C, входы RPWM и LPWM. При таймауте оба входа гасятся.

Руль, первый этап: сервопривод SG90 на GPIO Raspberry Pi, 50 Гц. На PCA9685 тяги серво не вешается: у микросхемы одна частота на все каналы.

Имя по схеме `{подсистема}-controller`. Пакет появится после URL из ADR 0006.
