# webrtc-client-go

Git submodule репозитория на Go. Принимает видеопоток по RTSP и отдаёт его оператору по WebRTC.
При подключении клиент вызывает `/robot/get_capabilities` через `robot-gateway`. Команды телеуправления уходят туда же по WebSocket, протокол rosbridge.

Сервис не зависит от библиотек ROS 2. Общего кода с ROS-пакетами нет: контракт записан в `docs/interfaces.md`.

Каталог пустой, пока нет URL подмодуля, см. ADR 0006. `go.mod` живёт в том репозитории.
