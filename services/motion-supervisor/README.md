# motion-supervisor

Узел ROS 2 Jazzy. Принимает команды телеуправления и публикует проверенные команды для `chassis-controller`.

Первая реализация может только пропускать команду дальше. Такой пропуск не является защитой: таймаут и безопасный ноль принадлежат `chassis-controller`.

Пакет `ament_python` появится здесь после утверждения типа команды. Тяга — знак и скважность IBT-2, руль — SG90 на GPIO, см. ADR 0006.
