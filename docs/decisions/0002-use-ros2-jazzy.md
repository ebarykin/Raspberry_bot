# 0002. ROS 2 Jazzy в контейнере

Статус: Accepted

## Контекст

Хост — Raspberry Pi 5, Debian 13 ARM64. Jazzy официально поставляется как Tier 1 для Ubuntu 24.04. На Debian 13 бинарных пакетов дистрибутива нет. Сторонние сборки для Trixie существуют, но это отдельный канал обновлений.

## Решение

Узлы `motion-supervisor` и `chassis-controller`, шлюз `robot-gateway` и интерфейсы работают на ROS 2 Jazzy внутри образа `ros:jazzy` (Ubuntu 24.04). На хост Jazzy не ставится.

## Последствия

Сборка и тесты ROS 2 идут в контейнере через `colcon`. Версия базового образа фиксируется тегом. Смена дистрибутива ROS требует нового ADR.
