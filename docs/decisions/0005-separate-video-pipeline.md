# 0005. Видео вне ROS 2

Статус: Accepted

## Контекст

Захват и кодирование уже живут отдельным контуром. Протаскивать кадры через топики ROS 2 только ради единого стека смешивает телеуправление и медиа.

## Решение

`capture-pipeline` захватывает видео и публикует RTSP. `webrtc-client-go` читает этот поток и отдаёт его оператору. Оба сервиса не зависят от ROS 2. Код захвата входит git subtree и сохраняет исходную структуру; одновременно с переносом его не рефакторят и не переписывают в узел ROS 2.

На Raspberry bot кодирует сам `capture-pipeline` (`x264enc`). Тот же процесс держит `GstRTSPServer` на `rtsp://127.0.0.1:8554/live`. `webrtc-client-go` только читает этот поток.

## Последствия

Сбой видео не обязан останавливать граф управления, и наоборот. Контракт потока записан в `docs/interfaces.md`, а не в общем Python-модуле.
