# 0001. Монорепозиторий

Статус: Accepted

## Контекст

Платформа состоит из пяти частей с разным стеком: WebRTC, rosbridge, два узла ROS 2 и видеозахват. Им нужны общие правила и один способ запуска, при этом WebRTC и захват не должны зависеть от ROS 2.

## Решение

Сервисы ROS 2, мост и документация лежат в этом репозитории. `capture-pipeline` входит сюда git subtree. `webrtc-client-go` — Git submodule: в этом репозитории хранится gitlink `services/webrtc-client-go`. У каждого сервиса свои зависимости и свой Dockerfile. Общей библиотеки между WebRTC и ROS 2 нет. Контракт описан в `docs/interfaces.md`.

## Последствия

Изменение границы сервиса сопровождается правкой документа контрактов. Сервис нельзя подключить импортом чужого пакета Python. Код `webrtc-client-go` обновляется в его репозитории и подтягивается сменой коммита подмодуля.
