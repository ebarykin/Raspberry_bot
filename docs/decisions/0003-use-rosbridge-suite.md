# 0003. Штатный rosbridge

Статус: Accepted

## Контекст

Оператору нужен доступ к графу ROS 2 без Cyclone DDS снаружи робота. `webrtc-client-go` написан на Go, поэтому мост говорит по сети, а не через общую библиотеку.

## Решение

`robot-gateway` запускает стандартный `rosbridge_server` из `rosbridge_suite` и узел `get_capabilities` в одном launch. Клиент ходит к rosbridge по WebSocket. Свой мост не пишется.

## Последствия

Поведение сокета и набор операций определяются rosbridge. Отступление от штатного сервера возможно только новым ADR с причиной, по которой `rosbridge_suite` недостаточен.
