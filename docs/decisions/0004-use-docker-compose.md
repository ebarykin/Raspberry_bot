# 0004. Docker Compose

Статус: Accepted

## Контекст

Пять сервисов нужно запускать одинаково на машине разработчика и на Raspberry Pi. На роботе нужны устройства и политика перезапуска, в разработке — монтирование исходников.

## Решение

Оркестрация — Docker Compose из трёх файлов:

- `compose.yaml` в корне — состав сервисов
- `deploy/compose.dev.yaml` — разработка
- `deploy/compose.robot.yaml` — робот

На роботе в эксплуатации используются заранее собранные образы с фиксированными версиями. Сборка при каждом старте на Pi не является рабочим режимом.

Файлов Compose в репозитории пока нет. Образ `robot-gateway` собирается своим Dockerfile. Тяга — PCA9685, руль на первом этапе — GPIO SG90, см. ADR 0006. URL subtree и submodule ещё не заданы.

## Последствия

Новый процесс в составе робота добавляется в базовый Compose и, если режим отличается, в один из оверлеев. `privileged: true` требует отдельного ADR.
